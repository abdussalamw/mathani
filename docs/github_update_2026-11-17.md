# تفاصيل تحديث مثاني المرفوع إلى GitHub

## القراءة والواجهة

- جعل فهرس السور قائمة بعمود واحد وصفوف بعرض الشاشة.
- إظهار أدوات القراءة افتراضيًا، وإضافة زر واضح للدخول في وضع ملء الشاشة وإعادة الأدوات بعد إخفائها.
- استعادة الأدوات عند فتح التفسير أو مشغّل الصوت أو نافذة الانتقال.
- تحسين تقليب الصفحات بحرية في الاتجاهات الأربعة. تُحسم السحبة المائلة لاتجاه واحد، ويُمنع بدء انتقال ثانٍ أثناء الانتقال الجاري.
- منع الالتفاف عند أول المصحف وآخره وإلغاء الانتقال القديم عند تغيير اتجاه القراءة أثناء الحركة.
- تثبيت رأس الصفحة والحفاظ على مساحة المصحف عند إخفاء الأدوات، مع معالجة تداخل محتوى الفهرس والإعدادات مع الشريط العلوي.

## الاستقرار والصوت

- تحسين تهيئة قائمة التلاوة ومعالجة أخطاء التشغيل وحالات التحميل والإغلاق والطلبات المتأخرة.
- دعم تطبيق نطاق التلاوة والتكرار مع الحفاظ على الموضع وحالة الإيقاف المؤقت عند طلب ذلك.
- عرض المقاطع التالية وتحسين وضوح عناصر التحكم ومساحات اللمس والشاشات الضيقة.
- دمج الطلبات المتزامنة للخطوط وبيانات الصفحات لتقليل العمل المكرر، ومنع نتائج الطلبات القديمة من استبدال الصفحة الأحدث.
- إضافة قياس اختياري لأزمنة الإطارات، غير مفعل افتراضيًا في نسخة الإصدار. لا تتضمن هذه التحديثات ادعاء تحسن أداء مقاس على الجهاز.

## Flutter وDart وقواعد البيانات

- توحيد بيئة المشروع على Flutter 3.50.0 وDart 3.14.0 وتحديث مسارات GitHub Actions وفق ملف `.fvmrc`.
- ترحيل الواجهة إلى Material UI وCupertino UI الحديثة مع تحديث مندوبات الترجمة وسكربت إعادة توليدها.
- الانتقال من Isar الأصلي إلى Isar Community 3.4.1، مع توحيد إصدارات المحرك والمكتبات الأصلية والمولّد.
- حفظ نسخة من قاعدة البيانات قبل فتحها لأول مرة بالمحرك الجديد وإزالة الحذف التلقائي عند تعذر الفتح.
- اختبار توافق قاعدة اصطناعية منشأة بالمحرك القديم: السجلات والمعرّفات والفهارس والكتابة وإعادة الفتح وحفظ النسخة الاحتياطية.
- تثبيت build_runner على 2.16.2 لتوافقه مع مولّد Isar؛ لا توجد تجاوزات قسرية للاعتماديات.

## المكتبات وأدوات البناء

- تحديث 11 مكتبة مباشرة و26 حزمة إجمالًا في المرحلة الأخيرة، ومنها المشاركة والخطوط والأرشفة وعرض SVG وSQLite ومنع سكون الشاشة وأدوات التحليل والأيقونات.
- ترحيل مشاركة الآية والتفسير إلى SharePlus وShareParams.
- إبقاء permission_handler على الفرع 12 المتوافق مع Android SDK 36؛ الفرع 13 يتطلب SDK 37.
- تحديث Gradle إلى 9.5.0 وAGP إلى 9.3.1 وKotlin إلى 2.4.20، واستخدام Build Tools 36.1.0 المثبتة.
- تفعيل ذاكرة نتائج Gradle ومعالجة تهيئة Kotlin لإضافة wakelock_plus المحدثة مع وضع التوافق الحالي.
- جعل نشر APK يدويًا فقط، مع أرشفة الملفات بأسماء تتضمن الإصدار ورقم البناء وعدم استبدال النسخ القديمة. رفع المصادر لا ينشر APK ولا يشغّل مسار النشر اليدوي.

## حدود التسميع والتحقق

- يتضمن الرفع أعمالًا سابقة في ملخصات المراجعة والإحصاءات أُنجزت قبل طلب تجميد التسميع. لم يُستأنف تطوير محرك التسميع أو نماذجه بعد ذلك الطلب.
- بقي record على 6.2.0 وsherpa_onnx على 1.13.2. لم يُشغّل استدلال النموذج خلال الاختبارات؛ مسار CPU القديم المذكور في تقارير المراجعة لم يُعتمد ولم يُعالج ضمن هذه الدفعة المجمدة.
- نجحت الاختبارات الـ53، ومنها اختبارا تنزيل وفك أرشيف المصحف ZIP وTAR.BZ2 واختبارات القراءة في الاتجاهات الأربعة.
- نجحت مهمة Gradle help للتحقق من تهيئة إضافات Android المحدثة في 49 ثانية. ليست هذه ترجمة Android كاملة أو اختبارًا أصليًا على الهاتف.
- التحليل النهائي بلا أخطاء أو تحذيرات، مع 17 ملاحظة أسلوبية في ملفات التسميع المجمدة. flutter analyze يرجع نتيجة غير ناجحة بسببها، وبالتالي قد تفشل مسارات CI التي تشترط خلو التحليل من الملاحظات؛ لم تُخفَ القواعد أو تُستثنَ الملفات لإظهار نجاح صوري.
- ثُبّت الإصدار 1.0.2 (11) سابقًا على الهاتف وأكد المستخدم رؤية تغييرات الواجهة. تحديث المكتبات الأخير موجود في المصادر فقط ولم يُبنَ له APK جديد؛ ملفات APK وبيانات المستخدم ومخرجات البناء المحلية غير مشمولة في الرفع.
