# مراجعة تحديث Flutter وDart — 17 نوفمبر 2026

## التحديث المنفذ

- Flutter: من 3.44.1 إلى 3.50.0، وDart: من 3.12.1 إلى 3.14.0.
- تثبيت إصدار Flutter في `.fvmrc` واستخدامه في جميع مسارات GitHub Actions.
- تحديث الحد الأدنى للأدوات في `pubspec.yaml` وتحديث `pubspec.lock`.
- تحديث دفعة محدودة ضمن قيود الحزم الحالية:
  - `dio`: 5.9.1 ← 5.11.1.
  - `just_audio`: 0.10.5 ← 0.10.6.
  - `path_provider`: 2.1.5 ← 2.1.6.
  - `shared_preferences`: 2.5.4 ← 2.5.6.
  - `sqflite`: 2.4.2 ← 2.4.2+1.
- حل الاعتماديات حدّث أيضًا حزم SDK والاختبارات، ومنها `intl` إلى 0.20.3.
- إزالة تكرار `assets/images/` وتحديث تعليمات التشغيل.
- بناء APK والنشر أصبحا يدويين من مسار Deploy مع تحديد وسم موجود؛ بناء arm64 واسم ملف يتضمن الإصدار ورقم البناء، دون استبدال مرفقات إصدار موجودة.

## التحقق

- قبل التحديث: نجحت الاختبارات الـ14؛ التحليل سجّل 338 ملاحظة.
- بعد التحديث: نجحت الاختبارات الـ14؛ التحليل سجّل 395 ملاحظة، منها 85 تحذيرًا و310 ملاحظات معلوماتية، دون أخطاء تحليل.
- أضيفت 57 ملاحظة: 53 عن إهمال استيراد `package:flutter/material.dart`، واثنتان عن أصناف ترجمة Material وCupertino القديمة، وتحذيران إضافيان عن فروع غير قابلة للوصول عند استخدام `??` مع قيم غير قابلة للعدم. كان المحلّل يرصد أصل مشكلتي `??` قبل الترقية أيضًا.
- `dart run build_runner build --delete-conflicting-outputs` نجح؛ لم تتغير ملفات نماذج Isar الناتجة مقارنة بالمستودع.
- مولّد Isar ما زال يفرض `analyzer 5.13.0`، وأصدر تحذيرًا عن عدم مواكبة إصدار اللغة؛ نجاح التوليد الحالي لا يضمن دعمه لجميع صيغ Dart الحديثة.
- فحص بنية YAML لمسارات CI نجح. لم تُشغّل GitHub Actions عن بُعد.
- لم يُبنَ APK ولم يُختبر التطبيق على جهاز. الاختبارات الحالية لا تثبت أداء الصوت والإضافات الأصلية أو ترحيل بيانات المستخدمين على Android.

## المراجعة التالية

1. معالجة ملاحظات التحليل الموجودة؛ CI ما زال يفشل عند `flutter analyze` بسبب هذه الملاحظات.
2. ترحيل Material وفق دليل Flutter، مع فحص توافق الحزم والثيمات والترجمة وواجهات RTL قبل تعميمه.
3. تقييم مستقبل Isar ومولّداته قبل تحديث حزم التوليد أو استخدام صيغ لغة جديدة داخل النماذج. لا تغيير لقاعدة البيانات ضمن هذه المرحلة.
4. مراجعة الترقيات الكبرى للحزم كلٌّ على حدة، خصوصًا التسجيل وONNX والمشاركة والصلاحيات.
5. اختبار القراءة والصوت والحفظ والتسميع على جهاز، وقياس الأداء قبل ادعاء تحسنه.

`flutter doctor` كشف أيضًا أن تراخيص Android SDK غير مقبولة؛ يلزم مراجعتها وقبولها من صاحب البيئة قبل بناء Android.

## الرجوع

يمكن الرجوع إلى Flutter 3.44.1 وإعدادات المشروع وملف القفل السابقين معًا. حُفظ تعديل SDK المحلي السابق (`objective_c` في ملف قفل SDK) في Git stash باسم `mathani-before-flutter-upgrade-2026-11-17` داخل `C:/src/flutter`، ولم يُحذف أو يُطبّق على الإصدار الجديد.
